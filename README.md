# Machine-Learning-Models
# Solving Linear Equations in Two Variables using Machine Learning

##  Project Overview
This project explores different machine learning models to predict the solutions of linear equations in two variables.

The dataset was sourced from Kaggle and contains coefficients of linear equations along with their corresponding solutions.

---

##  Models Implemented
The following models were implemented and evaluated:

- Linear Regression
- Support Vector Machines (Linear SVR)
- Random Forest Regressor
- K-Nearest Neighbors (KNN)
- Multilayer Perceptron (MLP)

Each model was evaluated using MAE, RMSE, and R² scores.

---

##  Best Performing Model
The **Multilayer Perceptron (MLP) with the Adam optimizer** performed the best overall.  
While several models underfit the data, the MLP was able to capture the underlying patterns more effectively.

## 📊 Dataset
- Source: Kaggle – *Linear Equation in 2 Variables*
